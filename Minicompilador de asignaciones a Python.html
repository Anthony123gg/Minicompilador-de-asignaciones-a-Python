Minicompilador de asignaciones a Python

Análisis léxico, sintáctico y semántico con traducción a Python y JSON

A) Caso

Un negocio de manualidades registra su inventario con instrucciones de asignación (insumo, costo_empaque, calculo). El minicompilador valida cada línea en tres fases y traduce las correctas a código Python y JSON.

  1. 1 · EntradaArchivo .txt o editor
  2. 2 · LéxicoExpresiones regulares
  3. 3 · SintácticoDescenso recursivo (CFG)
  4. 4 · SemánticoTabla de símbolos
  5. 5 · TraducciónPython y JSON

Ingreso de datos

Formato (una instrucción por línea): tipo nombre = expresión. Tipos: insumo, costo_empaque, calculo. Operadores: + − * / y paréntesis.
